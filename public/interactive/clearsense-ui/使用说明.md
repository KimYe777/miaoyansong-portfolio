# ClearSense UI 交互原型 v2

## 在线预览（本机）

- 给老师演示：`http://127.0.0.1:57820/index.html?welcome=1&demo=1`
- 首次启动（无演示控件）：`http://127.0.0.1:57820/index.html?welcome=1`
- 直接进入首页：`http://127.0.0.1:57820/index.html?welcome=0`
- 高风险演示：`http://127.0.0.1:57820/index.html?welcome=0&risk=high`

## 推荐体验路径

首次进入 → 开始使用 → 风险升高 → 点击风险水滴 → 查看完整判断 → 行动建议 → 记录身体感受 → 查看今日记录。

## 作为 App 使用

通过 Chrome 或 Edge 打开 HTTP 预览地址，在浏览器菜单中选择“安装应用”或“添加到主屏幕”。安装后将以独立窗口运行，并缓存核心页面和本地图片以支持离线浏览。

本原型使用本地模拟数据，不连接真实传感器、定位或医疗服务。
