# ClearSense 独立互动入口实施计划

日期：2026-08-07

## 实施顺序

1. 调整首页 ClearSense 项目文案区，加入作品集、产品模型、UI 原型三个原生链接。
2. 移除作品集详情页末尾的 `ClearSenseExperience`，保证 `/work/clearsense` 只保留 12 页原稿。
3. 新建两个独立路由与页面：`/experience/clearsense-model`、`/experience/clearsense-ui`。
4. 重构模型查看器：按模型体积和边界将两个底座网格固定，将四个上方产品网格放进统一拖动组；使用射线拾取、约束拖动和回位吸附。
5. 依据 ClearSense 渲染图分配珍珠白产品、暖白底座、冷灰蓝凹槽、深色缝隙与冷白发光细节材质，并加入柔光和接触阴影。
6. 将既有 UI 原型直接嵌入黑色手机模型屏框，去除灰色展示容器，保留返回和重新开始。
7. 更新样式和响应式规则，检查焦点、按钮名称、触控手势和 reduced-motion。
8. 生产构建；使用浏览器自动测试三入口、三路由、12页原稿、拖动分离/回位、UI 原型操作和 320–1440px 溢出。

## 模型对象判定

网页主装配过滤后共有 6 个网格：

- 两个最大体积网格：底座与底座外壳，固定。
- 其余四个网格：上方流线型产品及细节，加入同一 `THREE.Group`，保持相对位置。

拖动只改变上方组合沿装配轴的位移。指针按下时记录初始交点，移动时限制在 `0` 到最大拆装距离；接近 `0` 时吸附合上。拖动空白区域仍交给 `OrbitControls`。

## 完成定义

- 设计规格的 8 条验收标准全部通过。
- 原 Rhino、PDF 页面和 UI 原型源文件不被修改。
- 构建结果包含独立路由所需模型、Rhino WASM 与 UI 静态资源。
