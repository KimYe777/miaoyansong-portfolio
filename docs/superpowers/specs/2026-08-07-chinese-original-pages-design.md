# 中文作品集原页展示修订规格

日期：2026-08-07
状态：用户已明确确认并要求执行

## 目标

网站面向中国招聘方和中国院校评审。界面以中文为默认语言，四份已经完成编排的作品集不得被网站重新拆解、删减、重排或改写。

## 已选方案

采用“中文项目入口 + 原作品集完整连续阅读”。首页继续承担项目选择功能；进入项目后，从源PDF第1页到最后1页逐页展示。

未采用的方案：

- 摘要式网页案例页：阅读效率高，但会改变作者已完成的叙事与排版。
- 浏览器内嵌PDF：最省开发，但移动端、加载反馈和视觉统一性较差。

## 页面规则

1. 全站导航、首页标题、栏目、按钮、页脚、About页面和错误页改为中文。
2. ClearSense 展示12页，NightCare展示10页，租前眼展示14页，出去晃晃展示15页，共51页。
3. 每个项目的页面数组由文件名顺序生成并在数据层明确记录。
4. 作品集页面保持原比例、完整可见、不裁切，页面上不叠加网站文案。
5. 原作品集自身包含的中英文内容保持不变；网站外壳使用中文。
6. 第三个产品项目继续显示为“待补充”，但不创建虚假的详情页。
7. 图片延迟加载；首张图优先加载；提供清晰页码和图片替代文本。

## 验收标准

- 四个项目页分别显示12、10、14、15张原页。
- 页面顺序与源PDF一致，首尾页正确。
- 首页、导航和页脚不再出现面向用户的英文占位界面文案。
- 桌面和手机端均无横向溢出。
- 构建通过，四条项目路由返回200且图片无404。
