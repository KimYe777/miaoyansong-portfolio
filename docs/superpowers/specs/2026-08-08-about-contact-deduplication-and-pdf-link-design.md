# 关于我页面联系信息去重与 PDF 链接设计规格

日期：2026-08-08  
状态：用户已确认

## 目标

减少网站中重复的“联系”入口，让“关于我”页面成为个人资料、联系方式与完整 PDF 作品集的集中入口，同时保留其他页面页脚中的联系方式。

## 已选方案

采用“关于我页面集中联系，其他页面保留页脚”的方案：

1. 顶部主导航删除“联系”，只保留“作品”和“关于我”。
2. “关于我”页面保留暖白色背景中的“欢迎联系”区，以及可点击的电话和邮箱。
3. “关于我”页面不显示全站黑色联系页脚，避免同一页面出现两套联系信息。
4. 首页和其他常规页面继续显示黑色页脚，保留联系方式的全站可达性。
5. 在“关于我”页面的电话、邮箱下方增加“查看完整作品集 PDF”链接。

## PDF 文件策略

- 当前发布文件来源为 `缪岩松_产品设计与UIUX综合作品集_v6.pdf`。
- 发布目录中使用稳定文件名 `portfolio.pdf`，避免 GitHub Pages 对中文资源路径的兼容问题，也不把版本号写入网页链接。
- 链接在新标签页打开，并保留浏览器下载能力。
- 以后更新作品集时，只需使用新版 PDF 覆盖发布目录中的同名文件，不需要修改页面代码。
- 链接必须指向站内相对路径，兼容 GitHub Pages 的子路径部署。

## 组件行为

- `SiteHeader`：移除锚点式“联系”链接，不改变移动端菜单开关与“作品 / 关于我”路由。
- 页面壳层：根据当前路由判断是否渲染 `SiteFooter`；`/about` 不渲染，其他原有页面行为保持不变。
- `AboutPage`：在 `.about-contact-links` 中加入第三个 PDF 链接，沿用现有直线、文字层级和橙色交互反馈，不新增卡片或大按钮。

## 验收标准

1. 桌面端和手机端顶部导航均不再出现“联系”。
2. “关于我”页面只出现一处联系区域，页面底部没有黑色重复联系区。
3. 首页等其他原有页面仍显示黑色页脚。
4. 电话和邮箱链接可正常调用，PDF 链接返回有效 PDF，并在新标签页打开。
5. PDF 的网页路径不含 `v6`，后续可直接覆盖同名文件。
6. 桌面端和手机端无横向溢出，构建与快速视觉检查通过。
