# ClearSense 独立互动入口重构规格

日期：2026-08-07  
状态：用户已确认设计，待书面复核后实施

## 1. 修正目标

ClearSense 的完整作品集、产品模型和 UI 原型是三个并列体验，不再把模型与原型追加在 12 页作品集末尾。网站必须保留作品集原有阅读顺序，同时让招聘方或院校评审可从首页直接选择想看的内容。

本轮同时修正两个体验偏差：

- 3D 分离不是拆散内部零件，而是让上方流线型产品作为一个整体暂时离开底座。
- UI 原型不再放在灰色展示框内，但保留能明确表达 App 属性的真实手机模型屏框。

## 2. 信息架构

首页 ClearSense 项目展示区直接提供三个独立入口：

1. `查看完整作品集` → `/work/clearsense`
2. `体验产品模型` → `/experience/clearsense-model`
3. `体验 UI 原型` → `/experience/clearsense-ui`

三个入口使用原生链接，支持键盘访问、复制地址和浏览器前进后退。默认在当前标签页打开，不使用弹窗或强制新窗口。

`/work/clearsense` 只展示 12 页原作品集和下一个项目入口。现有页序、图片、放大查看和替代文本均保持不变。

## 3. 独立产品模型页

### 3.1 页面构成

- 保留轻量网站返回入口和页面名称。
- 3D 视图作为页面主体，不再嵌在作品集章节卡片中。
- 提供简短操作提示、`重新合上`和`复位视角`。
- 模型失败时显示 ClearSense 静态渲染图，并提供返回入口。

### 3.2 直接拖动分离

- 上方流线型产品识别为一个可拖动组合；它内部的 Rhino 网格保持相对位置，不单独爆炸。
- 底座及底座内部结构固定，不参与分离。
- 指针从上方产品开始拖动时，移动整个上方产品；松手后停留在当前位置。
- 移动范围被限制在产品与底座之间的合理拆装距离，不能拖出场景。
- 用户可把产品拖回底座附近；进入吸附范围后精确合上。
- 拖动空白区域旋转整个模型；滚轮或双指缩放。
- 手机端在用户明确点击进入操作前保持页面纵向滚动，避免手势冲突。

### 3.3 材质与光照

Rhino 文件中的产品对象没有已分配材质或可直接恢复的产品贴图，因此不采用把单张渲染图直接包裹到模型上的方案。网页根据已提供的 ClearSense 渲染图重建 PBR 外观：

- 上方产品：珍珠白、细腻、低粗糙度的塑料或涂层材质。
- 底座：暖白缎面塑料。
- 放置凹槽：冷灰蓝材质。
- 缝隙与内部遮挡：深灰中性色，增强结构层次。
- 可识别的灯带网格使用冷白偏蓝的自发光材质；若模型没有独立灯带几何，则不伪造错误贴图。
- 使用柔和摄影棚环境光、主辅光和接触阴影，使旋转时仍有稳定的产品渲染质感。

目标是视觉上接近项目渲染图，而不是承诺与原始离线渲染器像素级一致。

## 4. 独立 UI 原型页

- 页面主体是一台黑色真实感手机模型框。
- 已交付的 ClearSense HTML 原型直接填满手机屏幕区域，可正常点击、滚动和保存演示状态。
- 不添加灰色外框、展示卡片、浏览器窗口框或第二层设备容器。
- 手机模型之外仅保留低干扰的`返回作品`和`重新开始`操作。
- 桌面端手机居中并保留呼吸空间；手机端设备框尽量接近满屏，但不得裁切关键操作区。
- `重新开始`清理原型演示状态并重新载入；原型加载失败时提供独立打开链接。

## 5. 组件边界

- 首页项目组件负责渲染三个 ClearSense 入口，不承担互动逻辑。
- `ClearSenseModelPage` 只负责独立模型页布局和加载状态。
- `ClearSenseModelViewer` 负责 Rhino 加载、材质映射、相机、对象拾取、受限拖动和复位。
- `ClearSenseUiPage` 只负责手机模型框、原型 iframe、返回和重启。
- 原有 `ProjectPage` 恢复为通用作品集阅读器，不再挂载 ClearSense 专属体验区。

这些单元相互独立，未来替换 GLB、材质或 UI 原型文件时不会影响作品集阅读页。

## 6. 可访问性与动效

- 三个首页入口使用含义明确的链接文字，并有可见键盘焦点。
- 模型画布提供操作说明；复位和合上使用原生按钮。
- UI 原型 iframe 有准确标题，手机模型装饰不进入辅助技术阅读顺序。
- 自动动画不是体验前提；`prefers-reduced-motion` 下关闭非必要过渡。
- 颜色与控制文字满足中文界面的可读对比度。

## 7. 性能与错误处理

- 模型页进入后才加载 25.6 MB `.3dm` 和 Three.js 模块，首页与作品集页不加载模型。
- UI 原型只在进入独立原型页时加载。
- 加载过程展示明确中文状态，不出现空白画布。
- WebGL 不可用或模型失败时回退到静态渲染图。
- 原型 iframe 失败时保留可操作的重新载入和独立打开入口。

## 8. 验收标准

1. 首页 ClearSense 区域直接显示三个独立入口，桌面和手机均无需悬停即可访问。
2. 作品集路由只显示原有 12 页，顺序、内容和放大阅读不变。
3. 产品模型页可旋转、缩放，并能直接拖住上方产品整体离开底座；底座和内部零件不会散开。
4. 松手后上方产品停留，能够拖回并吸附合上；`重新合上`可随时复位分离状态。
5. 模型具有接近项目渲染图的白色产品材质、冷灰蓝凹槽、结构阴影和摄影棚光照，不再表现为无层次白模。
6. UI 原型页使用黑色手机模型框，界面直接填满屏幕区域且可交互，页面不存在灰色外层展示框。
7. 320、375、390、414、768、1440px 均无横向溢出，手机端模型和原型可正常操作。
8. 三条路由、键盘焦点、模型回退、原型重启、生产构建和浏览器控制台检查通过。

## 9. 明确不做

- 不改变或删减 ClearSense 作品集页面。
- 不拆散上方产品或底座的内部零件。
- 不用单张渲染图强行充当整机 UV 贴图。
- 不为 UI 原型增加灰色卡片、浏览器窗口或额外设备框。
- 不把模型或 UI 原型重新嵌回作品集末尾。
