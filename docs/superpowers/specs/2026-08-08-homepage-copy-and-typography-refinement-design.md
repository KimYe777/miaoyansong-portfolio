# 首页文字与排版精修设计

## 目标

保留首页现有“工业编辑部”视觉方向和“做产品，也做体验”的首屏表达，只调整用户明确指出的断行、标点和“关于我”两行标题排版。不修改项目内容、项目顺序、入口、模型或交互。

## 首屏

- 保留“做产品，”和“也做体验。”的现有文字与视觉关系。
- 第三行由“从问题到方案。”改为“从问题到方案”。
- 左下说明文字内容保持不变：
  `缪岩松，工业设计专业本科生。作品涵盖实体产品、服务系统与数字界面。`
- 在空间充足的电脑端让左下说明保持一个物理行，不再把“产品与数字界面”挤到下一行。
- 平板和手机端不强制单行，空间不足时允许自然换行，避免缩小文字或产生横向滚动。

## 产品设计章节

- 章节大标题由“产品设计作品。”改为“产品设计作品”。
- 小标签“主要作品 / 产品设计”保持不变，斜杠继续承担信息分组作用。

## 数字作品章节

- 黑色章节大标题固定为两行：
  1. `让复杂判断清楚`
  2. `也让轻松体验自然`
- 删除原文中的逗号与句号。
- 小标签“数字作品 / UI与交互”保持不变。

## 关于我章节

- 主标题固定为两行且不使用标点：
  1. `工业设计专业本科生`
  2. `关注产品与交互体验`
- 采用已确认的 B 版“字号反差与横线”排版：
  - 第一行使用较小字号、较宽字距并左对齐。
  - 第二行使用较大字号、较紧字距并右对齐。
  - 两行之间使用一条细横线建立结构。
- 小标签“关于我 / 方法”保持不变。
- 手机端仍严格保持两行，但降低字号和字距，不能产生横向溢出。

## 验收标准

1. 所有指定句号、逗号均已删除，其他文字不被改写。
2. 1440px 与常见笔记本宽度下，首屏左下说明保持一行。
3. 数字章节标题和关于我标题均严格保持两行。
4. 关于我标题呈现 B 版的字号反差、横线与右对齐关系。
5. 390px 手机宽度下无横向滚动，文字完整可读。
6. 项目入口、交互页面和作品集详情不受影响。
