# 日迹可选语音与独立抽屉交互设计

## 目标

在不破坏现有照片传送、老人终端接收、模型屏幕同步与照片打印闭环的前提下，补充两项体验：家人可以跳过录音只发送照片；模型底部抽屉可以独立打开和合上。

## 一、照片可不附带语音

- 保留现有“录一段声音”页面与语音分享路径。
- 在录音页面增加“跳过录音，只发照片”次要操作，点击后直接进入发送前确认页。
- 分享数据增加明确的语音状态；跳过后，确认页显示“本次未添加声音”。
- 发送内容仍包含所选照片、标题、日期、发送者和文字留言。
- 老人终端收到无语音分享后继续显示照片与文字，但“听声音”操作呈不可用状态，并标注“没有声音”，不能播放预设的虚假语音。
- 有语音路径保持当前行为，确保原有演示仍可完整体验。

## 二、模型抽屉独立开合

- 灰色抽屉面与抽屉内部组合为独立 Three.js 组，不依赖照片发送或打印状态。
- 点击模型底部灰色抽屉时，抽屉沿机身前方平滑拉出；再次点击时平滑合上。
- 点击模型其他区域仍交给轨道控制器处理旋转和缩放，不能因抽屉交互阻断现有操作。
- 页面操作说明增加“点击底部抽屉开合”。
- 提供可聚焦的“打开抽屉 / 合上抽屉”按钮作为键盘与触屏的稳定入口；按钮文字随状态变化。
- `prefers-reduced-motion: reduce` 下不播放位移动画，直接切换开合终点。
- 抽屉移动范围固定，合上时与暖白底座贴合，打开时不与机身或打印照片穿模。

## 数据与状态

- `RijiShare` 增加布尔语音状态，用于手机确认页和老人终端操作状态同步。
- 抽屉开合状态仅存在于模型查看器内部，与 `currentShare`、`printRequest` 和照片取走状态相互独立。
- 重置联动内容时不强制关闭抽屉；恢复模型视角时只重置相机，不改变抽屉状态。

## 可访问性与反馈

- 跳过录音使用真正的按钮，并具有明确中文文案。
- 无语音状态不只依赖颜色表达；老人终端同时显示文字状态并禁用声音按钮。
- 抽屉按钮使用 `aria-pressed` 表达开合状态，模型操作说明同步更新。
- 抽屉动画过程中忽略重复触发，动画结束后更新状态提示。

## 验收标准

1. 用户能够从录音页选择跳过，并顺利发送照片。
2. 无语音分享在手机确认页和老人终端均显示正确状态，且无法触发声音播放。
3. 原有附带语音的发送路径保持可用。
4. 抽屉可以通过点击模型抽屉或操作按钮独立打开与合上。
5. 抽屉开合不会影响模型旋转、缩放、屏幕同步与照片打印。
6. 桌面、手机、键盘操作和减少动态效果模式均可完成上述流程。
